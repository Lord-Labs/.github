# Contributing to LORD Labs

Thanks for helping. Documentation, translations, accessibility fixes, reproducible bug reports, and focused code changes all count.

1. Find the relevant project in the [organization profile](https://github.com/Lord-Labs#readme). Read its README, contribution guide, and any repository instructions. Project-specific guidance takes precedence over these defaults.
2. Search existing issues and pull requests. Report a reproducible bug or discuss a substantial feature before implementing it. Never include credentials, private meeting content, download links with tokens, or household data.
3. Fork the repository and create a short-lived branch. Keep one pull request focused on one problem; avoid unrelated formatting or dependency updates.
4. Run the checks documented in that repository. Describe exactly what ran and any environment or platform you could not test. Preserve accessibility and English/Arabic behavior where applicable.
5. Open a pull request with the problem, resulting behavior, linked issue, and verification. Add screenshots for visible changes. Wait for the applicable checks and maintainer review; do not treat an unchecked box as a passing test.

Maintainers may request a smaller change, additional evidence, or a discussion before accepting a proposal. Contributions use the destination repository's license and third-party asset terms. This repository does not impose a separate contributor license agreement.

For questions see [Support](https://github.com/Lord-Labs/.github/blob/main/SUPPORT.md). For vulnerabilities use [private security reporting](https://github.com/Lord-Labs/.github/blob/main/SECURITY.md).

## بالعربي

اختار المشروع المناسب واقرأ تعليماته، وراجع الـ Issues الموجودة قبل ما تبدأ. خلّي التغيير محدد، وحافظ على دعم العربي والإنجليزي وإمكانية الوصول. وضّح في الـ Pull Request إيه اتغير وإيه اختبرته فعليًا. ما تنشرش بيانات خاصة أو مفاتيح سرية؛ استخدم الإبلاغ الأمني الخاص.
