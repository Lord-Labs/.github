# Getting help

Choose the repository that owns the problem:

| Question | Repository |
| --- | --- |
| Downloads, Windows desktop, browser handoff | [ZipZap](https://github.com/Lord-Labs/ZipZap/issues) |
| Meetings, captions, meeting memory, self-hosting LOR. | [lor](https://github.com/Lord-Labs/lor/issues) |
| NetScope foundation, measurement research, contribution questions | [NetScope](https://github.com/Lord-Labs/NetScope/issues) |
| ZipZap landing page or website download link | [zipzap-website](https://github.com/Lord-Labs/zipzap-website/issues) |
| LORD Labs homepage, journal, or translations | [lordlabs.tech](https://github.com/Lord-Labs/lordlabs.tech/issues) |
| Organization profile or shared community guidance | [.github](https://github.com/Lord-Labs/.github/issues) |

Read the README and search existing issues before opening a report. Include the version/URL, operating system and browser where relevant, exact reproduction steps, expected behavior, actual behavior, and sanitized logs or screenshots. English and Arabic are welcome.

Use the repository's issue forms for bugs and feature requests. The [shared roadmap](https://github.com/orgs/Lord-Labs/projects/1) is a view of tracked work, not a delivery-date commitment. NetScope remains at foundation stage; check its actual state before expecting monitoring or billing capabilities.

For organization-wide questions or ideas, use [Discussions](https://github.com/orgs/Lord-Labs/discussions). Reproducible bugs and scoped implementation work belong in the affected repository's issues.

Support is provided by maintainers and contributors as available. There is no guaranteed response time. Security reports belong in [private security reporting](https://github.com/Lord-Labs/.github/blob/main/SECURITY.md), not public support threads.
