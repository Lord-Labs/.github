### Build with us

Small fixes, documentation, accessibility work, translations, testing, and thoughtful product feedback are welcome. Read the project's contribution guide and existing issues first. English and Arabic reports are both welcome; follow the repository's convention for engineering documents and pull requests.

- [Find issues asking for help](https://github.com/search?q=org%3ALord-Labs+is%3Aissue+is%3Aopen+label%3A%22help+wanted%22&type=issues)
- [Get help](https://github.com/Lord-Labs/.github/blob/main/SUPPORT.md)
- [Report a security concern privately](https://github.com/Lord-Labs/.github/blob/main/SECURITY.md)

Release notes and each repository's README describe what is available today. A roadmap item is planned work, not a shipped feature. Licenses are defined per repository; names, logos, and third-party assets keep their own terms.

### بالعربي

**LORD Labs** معمل مستقل بنبني فيه أدوات مفتوحة المصدر ومنتجات رقمية باهتمام بالتفاصيل، وبالعربي والإنجليزي.

ابدأ بـ [ZipZap](https://github.com/Lord-Labs/ZipZap) لتنزيل الملفات على ويندوز، أو [LOR.](https://github.com/Lord-Labs/lor) لاجتماعات الفيديو. مشروع [NetScope](https://github.com/Lord-Labs/NetScope) لسه في مرحلة التأسيس؛ قياس الاستهلاك والفواتير مش ميزات جاهزة حاليًا.

مساهمتك مرحب بيها، سواء إصلاح صغير، ترجمة، توثيق أو تجربة استخدام. راجع تعليمات المشروع قبل فتح Pull Request، وبلّغ عن المشاكل الأمنية بشكل خاص من تبويب **Security** في الريبو المعني.
